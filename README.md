## 📚 Module

### 🧩 Programmierung 2  
In diesem Modul habe ich meinen Beleg aus dem ersten Semester weiterentwickelt.  
Das bestehende **Sudoku-Spiel** wurde vollständig in **C++** neu geschrieben  
und objektorientiert umgesetzt.

🧠 **Lernziele:**
- Anwendung der **Objektorientierten Programmierung (OOP)** in C++  
  (Klassen, Objekte, Konstruktoren, Vererbung, Kapselung)
- Strukturierung größerer Softwareprojekte
- Erweiterbarkeit und Wiederverwendbarkeit von Code

🎮 **Projektbeschreibung:**
- Das Sudoku-Spiel basiert auf dem Projekt aus **Programmierung 1**
- Spielzustände können gespeichert und rückgängig gemacht werden
- Verbesserte Strukturierung durch eigene Klassen für Spiellogik, Benutzeroberfläche und Steuerung

📎 **Projekt:**  
👉 [Zum Sudoku-Repository](https://github.com/dana-lng/Sodoku.C-OOP)
