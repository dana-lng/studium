## 📚 Module

### 🧩 Programmierung 1  
Im Modul **Programmierung 1** habe ich einen **Beleg (Projekt)** entwickelt,  
bei dem ein **Sudoku-Spiel** programmiert werden musste.  

🧠 **Ziele & Inhalte:**
- Einführung in die Grundlagen der Programmierung (z. B. Variablen, Schleifen, Bedingungen)
- Verständnis für logische Strukturen und Algorithmen
- Eigenständige Umsetzung eines kleinen Spiels in Java

🎮 **Projektbeschreibung:**

Das Sudoku-Spiel bietet:
- Generierung eines spielbaren Sudoku-Feldes  
- Eingabevalidierung und Lösungsprüfung  
- Möglichkeit, das Sudoku automatisch lösen zu lassen
